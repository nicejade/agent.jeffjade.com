## 工作流全景

```
代码理解 → 方案设计 → 逐步实现 → 测试验证 → 代码审查 → 提交部署
```

## 代码理解阶段

- 让 Claude Code 快速理解陌生项目
- 生成项目结构图与模块依赖关系
- 识别技术债务与潜在问题
- 实战：接手遗留代码库的第一步

## 调试工作流

- 粘贴错误日志，让 Claude 分析根因
- 截图调试：界面异常、图表问题
- 二分法定位：让 Claude 帮你缩小范围
- 修复 → 验证 → 回归的闭环

## 重构工作流

- 提取函数 / 组件
- 跨文件重命名与移动
- 设计模式转换
- 依赖升级与迁移
- 重构的安全网：用 Git 保护每一步

## 新功能构建

- Plan Mode 先行设计方案
- 逐文件实现，每步验证
- 测试驱动：先写测试，再让 Claude 实现
- 多文件协同编辑

## Git 集成工作流

- 自动生成规范的 Commit Message
- PR 描述自动生成
- 代码审查：让 Claude Code Review 你的改动
- 冲突解决辅助

## 部署与 CI/CD

- 生成 Dockerfile 与部署配置
- GitHub Actions 工作流编写
- 环境变量与密钥管理
