## 定位：非聊天工具，而是系统级 Agent

- Claude Code 与 Claude.ai 的本质区别：权限边界、上下文来源、执行能力
- 从"问答式 AI"到"代理式 AI"的范式跃迁
- 核心特性：本地文件系统访问、Shell 执行、Git 感知、持续会话

## Agentic Coding 范式

- 你不再"写代码"，而是"指挥 Agent 写代码"
- Agent 主动探索、规划、执行、验证的闭环
- 人在回路（Human-in-the-Loop）的安全设计

## 与传统开发工具的对比

- vs. IDE 自动补全（Copilot / Cursor Tab）：从补全到自主执行
- vs. 聊天式 AI 编程助手：上下文持久性与工具调用深度
- 适用边界：何时用 Claude Code，何时用其他工具
