## 核心优势

- **上下文深度**：整个代码库作为上下文，而非单个文件
- **工具自主调用**：自动读写文件、执行命令、搜索代码
- **持续会话**：跨会话记忆与项目理解积累
- **多任务并行**：子代理并行处理独立任务

## 与其他 AI 编程工具的差异对比

| 维度 | Claude Code | Cursor | Copilot | Continue |
|------|-------------|--------|---------|----------|
| 执行能力 | 自主执行 Shell | 仅代码编辑 | 仅补全/聊天 | 仅补全/聊天 |
| 上下文范围 | 全代码库 | 当前项目 | 当前文件 | 可配置 |
| 权限级别 | 系统级 | IDE 级 | IDE 级 | IDE 级 |
| 适用模式 | Agentic | 交互式 | 辅助式 | 辅助式 |

## 最适合的开发任务

- 跨文件重构与迁移
- 新功能端到端实现
- 代码审查与 Bug 修复
- 文档与测试生成
- DevOps 与 CI/CD 配置

## 不太适合的场景

- 单行代码补全
- 需要实时图形界面的操作
- 对延迟极度敏感的交互
