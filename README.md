# 智能体漫游

Agent 知识站 [agent.jeffjade.com](https://agent.jeffjade.com)，基于 Astro、Starlight、Svelte 与 Tailwind CSS 构建。

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

## Content

- `/` - Site home (智能体漫游).
- `/claude-code/` - Claude Code guide landing and chapter catalog.
- `/claude-code-guide/` - Claude Code tutorial chapters (Starlight docs).
